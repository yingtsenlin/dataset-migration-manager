# Quality checklist

After each migration, verify:

## Metadata

- dataset name exists
- description exists
- tags exist
- description follows wording rules
- tags follow approved vocabulary

## Content

- expected files were uploaded
- sample count is reasonable
- annotations are present if required
- images are readable if required

## Duplicate cleanup

- only one newest same-name dataset remains
- no unexpected same-name old versions remain

## Reporting

Include:

- created dataset name
- upload status
- metadata used
- duplicate cleanup result
- unresolved issues
